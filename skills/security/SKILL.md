# Security Review

- 只检查本次改动和相邻可达路径，不无界扫描。
- 密钥、token、Cookie 和私钥只能来自环境变量或密钥管理，不写入仓库或日志。
- 外部输入在系统边界解析；SQL、命令、URL、文件路径和 HTML 使用结构化安全接口。
- 核对鉴权、授权、权限提升、敏感数据出口、日志脱敏与第三方网络端点。
- 外部 MCP、hook 和二进制要核对固定版本、执行命令、数据范围、失败语义与卸载路径。
- 发现高风险问题时先停止相关路径，给出复现证据和最小修复，不用静默回退。
