# Testing

- 测试命名描述行为和条件；一个测试只验证一个主要结果。
- 优先真实对象和轻量 fake；只有外部 SaaS、时钟或随机性等真实不可控边界才使用 mock。
- 回归修复先看到测试因目标缺陷失败，再实现最小修复并重跑。
- 单元测试覆盖纯逻辑，集成测试覆盖模块/协议边界，关键用户路径使用 E2E。
- 不用 sleep、顺序依赖、无断言测试或自然语言快照制造虚假覆盖。
- 项目既有测试命令、fixture 和 CI 约定优先；不为没有测试体系的项目新造基础设施。
