# Integrated Engineering

用一个主流程串起现有能力，避免同时触发多个相互竞争的工作流。

1. 读取项目规则、需求、调用点、测试和运行入口，写出可观察验收条件。
2. 多步骤任务建立短计划，只保留一个进行中步骤；明确文件所有权、风险和回滚。
3. 按任务选择一个主 skill：编程、调试、前端、评审或团队编排走对应 OMO/Hallmark 工作流。
4. 实现保持最小完整改动；隐蔽回归先测试，普通配置或文案改动使用针对性验证。
5. 真实验证：页面用浏览器，服务用运行端点，库用消费者，CLI/TUI 用实际命令。
6. 完成前检查 diff、测试、秘密泄露和用户已有修改；报告证据、限制、备份与回滚。

外部 MCP、插件、hook、二进制或远程写操作必须先确认来源和数据边界。此 skill 不覆盖项目规则，也不绕过现有 OMO hooks 与 MCP。
